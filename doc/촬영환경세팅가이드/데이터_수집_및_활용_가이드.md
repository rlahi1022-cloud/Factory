# 데이터 수집 및 활용 가이드

---

## 1. 시료 선정 기준

| 기준 | 이유 |
|------|------|
| 불투명 라벨 제품 | 흑백 카메라에서 안정적인 Gray Level 유지, 라벨 결함 검출에 유리 |
| 매끈한 원통형 병체 | 굴곡이 많으면 그림자가 복잡 → PatchCore 배경 학습 방해 |
| 캡-병체 명암 차이 ≥ 30 (Gray Level) | 흑백에서 YOLO가 캡 경계를 안정적으로 탐지하기 위한 최소 조건 |

---

## 2. 촬영 환경 구축

> 아래 가능한 수준에서 실시.

### 2-1. 하우징 (터널형)

- **암실이 아닌 터널형 구조**: 실제 공장은 외부 광이 존재하므로, 양쪽이 뚫린 터널 형태로 제작
- **내부는 무광 검정 처리**: 검은색 부직포 또는 색지로 도배하여 난반사 억제
- **외부 광 유입 허용**: 외부 광 유입은 허용하되, 제어 조명이 외부 광을 압도하도록 광량 확보

### 2-2. 지그 (Jig)

- **재질**: 검은색 EVA 폼 (부스러기 없음, 반사 억제)
- **구조**: 병 바닥 지름보다 1~2mm 큰 원형 홈 → 자연스러운 위치 편차 허용
- **목적**: 병 고정 + 통제된 범위 내의 미세 편차 구현 (PatchCore 강건성 확보)

### 2-3. 조명 (단계별 이원화)

| 구분 | 1단계 (빈 용기) | 2단계 (조립 검사) |
|------|------------------|---------------------|
| 조명 방식 | 백라이트 (투과광) | 전면/측면 확산 조명 (반사광) |
| 히스토그램 기준 | 배경 포화(255) 허용, 병 내부 굴절 영역 ≤ 240 | 가장 밝은 하이라이트 ≤ 240 (포화 엄격 제한) |
| 목적 | 병 실루엣 대비 극대화 → 이물질이 Dark spot으로 드러남 | 캡/라벨 텍스처 보존 → 표면 결함 검출 |

**공통 사항**

- **확산판**: 트레이싱지 2~3장 겹쳐서 광원 형태가 안 보이는 면 광원 구현
- **편광 필터**: 조명 앞 1장 + 카메라 렌즈 앞 1장 (직교 배치) → 표면 반사광 제거
- **포화 방지**: 조명을 밝게 하되 히스토그램 우측 끝이 기준을 넘지 않도록 조절
- **플리커 체크**: 연속 5장 촬영 → 평균 밝기 변동이 ±2% 이내인지 확인. 초과 시 배터리 LED 랜턴으로 교체?

### 2-4. 카메라 파라미터

| 파라미터 | 설정값 | 이유 |
|---------|--------|------|
| Pixel Format | Mono8 (8bit 흑백) | PatchCore 입력 호환, 처리 속도 확보 |
| Gain | 0 (최소) | 노이즈 억제, 밝기는 조명으로만 확보 |
| Exposure Time | 병 정지 시 ~20ms / 이동 시 ≤1ms | Motion Blur 방지 |

## 3. 데이터 수집 계획 (단계별 분리)

### 3-1. 1단계 — 빈 용기 외관 결함 탐지

| 구분 | 수량 | 설명 |
|------|------|------|
| Normal | 150장 | 완전 정지 50장 + 지그 유격 위치 편차 50장 + 밝기 미세 편차 50장 |
| Defect (Easy) | ~20장 | 유성 매직 낙서, 테이프 부착 |
| Defect (Hard) | ~20장 | 미세 실 조각 부착, 얇은 스크래치 |

- **조명**: 백라이트 (투과광)
- **파이프라인**: 전처리 → PatchCore 단독 추론
- **학습 정책**: PatchCore 학습에는 Normal 데이터만 사용 (비지도 학습). Defect는 평가(검증)용

### 3-2. 2단계 — 캡+라벨+충전량 조립 검사

| 구분 | 수량 | 설명 |
|------|------|------|
| Normal | 150장 | 동일 제품 완성품, 지그 유격 편차 포함 |
| Defect - 캡 (Easy) | ~10장 | 캡 완전 미체결, 캡 없음 |
| Defect - 캡 (Hard) | ~10장 | 캡 살짝 기울어짐 (Cocked cap) |
| Defect - 라벨 (Easy) | ~10장 | 라벨 찢어짐, 라벨 없음 |
| Defect - 라벨 (Hard) | ~10장 | 라벨 미세 들뜸, 기포 |
| Defect - 충전량 | ~10장 | 과충전 / 미충전 (물 높이 조절) |

- **조명**: 전면/측면 확산 조명
- **학습 정책**: YOLO11 학습에는 Normal + Defect 모두 사용 (지도 학습, 바운딩 박스 어노테이션 필요)
- **탐지 클래스**: `cap`, `label`, `liquid_level`

## 4. 데이터 활용 파이프라인

### 4-1. 1단계 파이프라인

```
Pylon Camera → Grab → BGR→Gray 변환 → PatchCore 추론 
→ 이상 점수(Anomaly Score) 출력 → 임계값 비교 → OK/NG 판정
```

### 4-2. 2단계 파이프라인 (이상 검출 로직 통합본)

```
Pylon Camera → Grab → BGR→Gray 변환 → YOLO 기반 ROI 분할 
→ 영역별 PatchCore 이상 검출 → 최종 통합 판정
```

#### [Stage A] YOLO11 ROI 탐지

- `cap`, `label`, `liquid_level` 영역을 탐지합니다.

#### [Stage B] PatchCore용 전처리 (1단계와 동등화)

- YOLO로 탐지된 Bounding Box에 상대적 Buffer(3~5%)를 적용하여 여백을 확보합니다.
- 각 영역을 **224×224**로 Resize하여 1단계와 동일한 입력 규격을 맞춥니다.

#### [Stage C] 패치별 이상 검출 (1단계와 동일 로직)

- **캡(Cap) 패치**: PatchCore 추론 → 이상 점수(Anomaly Score) 산출
- **라벨(Label) 패치**: PatchCore 추론 → 이상 점수(Anomaly Score) 산출
- **액면(Liquid) 패치**: OpenCV(Hough Line) 기반 수위 판정 및 기울기 분석

#### [Stage D] 이상 점수 기반 판정 (1단계와 동일 로직)

- 산출된 각 영역별 이상 점수를 미리 설정된 임계값(Threshold)과 비교합니다.
- 하나라도 임계값을 초과하면 **NG(불량)**, 모두 미만이면 **OK(양호)**로 판정합니다.

> ※ 이 과정에서 1단계와 마찬가지로 이상 부위 시각화(Heatmap)를 생성하여 저장합니다.

## 5. 촬영 시 주의사항

| 항목 | 내용 |
|------|------|
| 카메라 고정 | 미세 흔들림도 PatchCore 성능 급감 → 박스에 카메라 매립 또는 견고한 거치대 사용 |
| 병 방향 고정 | PatchCore는 정렬된 이미지 기반 → 의도적 회전 금지, 자연 편차만 허용 |
| 유통기한 인쇄 | 위치가 매번 바뀌면 결함으로 오탐 → 인쇄가 없는 면을 촬영하거나 ROI에서 제외 |
| 기포 안정화 | 2단계 촬영 시 액체 이동 후 기포 안정화 시간 필요 (기포 → 이물질 오탐) |
| 불량 난이도 | Easy(뚜렷한 결함)와 Hard(미세 결함) 구분하여 수집 → 모델 성능 과대평가 방지 |
